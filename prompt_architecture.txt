5. **Ignore Generated Dirs:** Skip `build/`, `.dart_tool/`, `.gradle/`, `.idea/`, and `.git/`.
6. **Scannable & Thorough:** Use clear markdown headings, comparison tables, code blocks, and mathematical formulas matching live Dart code.

### 3. Dynamic Timeline Math & 3-Zone Silence Distribution Engine
Detail the exact implementation in `SessionQueueEngine` (`lib/engine/session_queue_engine.dart`):
- **Total Duration Resolution ($T_{\text{total}}$):** Validated range $60\text{s} \le T_{\text{total}} \le 5400\text{s}$ (1 to 90 min) resolved from duration slider or target clock time.
- **Opening Bell Removal:** Opening bell eliminated; session opens with silent verbal entry.
- **3-Zone Dynamic Silence Distribution Architecture:**
  - **Zone 1 (Fixed Framing Bridges):** $S01, S02, S13, S14$ receive fixed 8.0s post-silence gap; $S15$ receives 5.0s; $S16$ receives 0.0s.
  - **Zone 2 (Instruction Gaps, $S03$–$S11$):** Receives 68% of dynamic silence pool (`dynamicSilencePool * 0.68`). Weighted by segment type (Settling $S03$–$S07$ = 1.0; Core Practice $S08$–$S11$ = 1.5). Minimum threshold 45.0s per segment.
  - **Zone 3 (Deep Silence Integration, $S12$):** Absorbs remaining 32% of dynamic silence pool (`dynamicSilencePool * 0.32` + remainder).
- **Segment Pruning Priority Order (Sessions $\ge 300\text{s}$):**
  - Protected Frame: `$S01, S02, S12, S13, S15, S16$` (never pruned).
  - Protected Signature Pairs (never pruned for that archetype):
    - Focused Calm: `S03, S08`
    - Trauma-Informed: `S04, S05`
    - Open Awareness: `S08, S09`
    - Metta: `S04, S11`
    - Custom Practices: Last 2 active segments in $S03$–$S11$.
  - Pruning Priority Order (dropped one-by-one when Zone 2 silence < 45s): `['S14', 'S06', 'S04', 'S03', 'S07', 'S10', 'S08']`.
- **Test Mode Bypass (< 300s):**
  - $\le 120\text{s}$: Truncated to 4 segments (`S01`, primary signature segment, `S12`, `S16`).
  - $121\text{s}$–$299\text{s}$: Protected frame + protected signature pair.
